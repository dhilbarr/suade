# Suade — agent onboarding

Suade is a **narrative compiler and deck critic**, shipped as a Claude Code / Cowork plugin. It architects and lints presentation *arguments*. It never renders slides — that is a load-bearing product decision, not a missing feature.

**Read [docs/CONTEXT.md](docs/CONTEXT.md) before non-trivial work** (full product state, decisions + rationale). **Pick tasks from [docs/ROADMAP.md](docs/ROADMAP.md)** (sequenced queue with acceptance criteria).

## Working agreements (from the founder, binding)

- **Active branch: `suade-aug-2026`.** Do not push to `main` or touch other branches without explicit founder instruction.
- **Ship-first testing.** No localhost/browser test loops, no preview servers. Deterministic CLI checks (fixtures, validators) are fine. Push every completed batch; verify from real usage and logs.
- **Zero runtime dependencies.** Scripts are plain node (`node:` builtins only). No npm installs, no API calls at plugin runtime. Every script has a documented no-script fallback for Cowork sandboxes (see the fallback tables in each SKILL.md).
- **Kill list** (do not reintroduce): pixel rendering, embeddings infra (scale trigger documented in CONTEXT), Supabase, GCP/Vertex, bare MCP server, accounts/telemetry.
- **Founder-taste zones — flag, don't unilaterally rewrite:** the critic's voice paragraph in `skills/deck-critique/SKILL.md` and the scoring anchors in `skills/deck-critique/references/rubric.md`.
- Commit messages end with `Co-Authored-By: Claude <model> <noreply@anthropic.com>`.

## Repo map

- `skills/` — the product logic (deck-critique = the wedge; narrative-blueprint = the core loop; render-handoff = the boundary). `commands/` are thin wrappers only.
- `data/audiences/` — 13 audience lens files (`yc-demo-day` + `board-quarterly` edited for critique; the rest marked RAW, editing them is roadmap work).
- `data/patterns/` — 900-record annotated corpus, 14 tier-1 decks, ids `<deck>#sNNN`. Retrieval = grep `works_for`/`abstract_pattern` + model-in-the-loop; no embeddings by design.
- `schemas/` — six JSON Schemas sharing enums via `defs.schema.json`. `blueprint.md` is the source of truth; `blueprint.json` is DERIVED (`node scripts/validate.mjs compile`), never hand-edited.
- `tools/` — founder-local generators. `data/patterns/README.md` and the corpus are GENERATED by `tools/build-corpus.mjs`; edit the generator, then rerun it. Requires the v1 repo at `~/Developer/suade-ai-anthropic-sdk` (founder's machine only).
- `tools/corpus-private/` — gitignored image-url map; never commit it.

## Verify before claiming done

```
node scripts/validate.mjs compile <fixture blueprint.md>   # compiles + validates
node scripts/validate.mjs validate <artifact.json>          # schema check
node tools/build-corpus.mjs                                 # must end: 900 records, 0 dupes (founder machine only)
```

Critique outputs get a **full reference check**: every cited slide exists and says what the report claims; every cited pattern id exists in `data/patterns/index.json`. One fabricated reference is a shipped bug.
